# GTAS Travel Authorization

1. [Download GTAS-NNSA.msapp](./GTAS-NNSA.msapp). On the GitHub file page, select **Download raw file**. In Power Apps, choose **Apps → Import app → From file (.msapp)**.
2. [Download the HTML preview](./GTAS-NNSA-Preview.html) and open it in a browser. It uses sample requests.

The app opens to the connected SharePoint request screen. **Travel workspace** opens the expanded workflow. See the [V2 deployment guide](./GTAS/PowerApps-v2/README.md) for the additional SharePoint lists, Power Automate flows, and permission setup.

The navy, blue, and gold build passed local Microsoft packaging and reopen checks. Verify the new build in Power Apps Studio before publishing.
